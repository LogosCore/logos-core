# Logos frontend

Core's web UI: a React 19 + TypeScript single-page app built with Vite. It
talks to core's GraphQL API (`/api/v1/graphql`, subscriptions over
`/api/v1/graphql/ws`) and its REST endpoints, under `VITE_API_URL`
(`/api/v1`). How the frontend and core fit together, and the rules both keep,
are in the repository's `CLAUDE.md`; what core does is on the docs site,
https://logoscore.github.io/logos-docs/.

## Run

In the dev stack (`make services` at the repository's root) it runs in
`logos-frontend-dev`, Vite with hot reload, behind nginx: open
http://localhost:8080. Alone:

```bash
npm ci
npm run dev        # Vite on :5173; /api/v1 has to reach core
```

## Commands

| | |
|---|---|
| `npm run build` | `tsc -b && vite build`: the typecheck, then the production build in `dist/` |
| `npm run test:run` | vitest once (`npm test` watches) |
| `npm run lint` | eslint, with the React Compiler's rules; the debt left is noted per file in `eslint.config.js` |
| `npm run budget` | after a build: the first-paint bundle against its ceiling (`scripts/check-bundle-budget.mjs`) |
| `npm run codegen` | GraphQL types and documents from core's schema (`../core/pkg/graphql/schema`) and `src/graphql/operations`, into `src/graphql/gql` |
| `npm run build:viewer` | the HTML export's offline viewer, built into core (`make viewer` at the root does the same) |
| `npm run gen:icon-tags` | lucide's search keywords (`src/components/wiki/lucide-tags.generated.ts`), after a `lucide-react` bump |
| `npm run gen:wordlists`, `npm run gen:drawing-icons` | the other generated data files, from their scripts in `scripts/` |

CI (`.github/workflows/ci-frontend.yml`) runs the tests, the lint and the
build with the bundle budget on every push touching `frontend/`. The image
(`publish-frontend.yml`) is nginx serving `dist/`, built on the runner.

## Layout

- `src/pages`: one component per route (`App.tsx` has the routes).
- `src/components`: the UI, by area (`modules`, `wiki`, `ui` for the shared
  pieces, and the rest).
- `src/graphql`: `operations` (the queries, mutations and subscriptions),
  `gql` (generated by `npm run codegen`: do not edit), `hooks`.
- `src/lib`, `src/hooks`, `src/stores`, `src/providers`, `src/services`: shared
  logic, hooks, state and context.
- `src/viewer`: the HTML export's offline viewer (`vite.viewer.config.ts`).
